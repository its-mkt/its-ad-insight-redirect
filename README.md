# its-ad-insight-redirect

옛 주소 `its-ad-insight.itket.com` 으로 들어온 접속을 새 주소 `https://its.itket.com/ad-insight/` 로 넘기는 GitHub Pages 사이트.
경로·검색어는 그대로 붙인다 (`/itket/usage` → `/ad-insight/itket/usage`, 깊은 주소는 404.html 이 같은 일을 한다). 본체는 [its-mkt/ad-insight](https://github.com/its-mkt/ad-insight).

- 사용자 도메인은 본체 저장소가 자체 도메인을 뗀 뒤에 `its-ad-insight.itket.com` 으로 단다 (Pages 도메인은 저장소 하나에만 연결된다)
- 옛 CNAME 을 NHN 에서 지우면 이 저장소는 지워도 된다
