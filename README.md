# its-ad-insight-redirect

옛 주소 `its-ad-insight.itket.com` 으로 들어온 접속을 새 주소 `ad-insight.itket.com` 으로 넘겨 주는 GitHub Pages 사이트.
경로·검색어는 그대로 붙여 넘긴다 (깊은 주소는 404.html 이 같은 일을 한다). 대시보드 본체는 [its-mkt/ad-insight](https://github.com/its-mkt/ad-insight).

- 사용자 도메인은 본체 저장소가 `ad-insight.itket.com` 으로 옮긴 뒤에 이 저장소에 `its-ad-insight.itket.com` 으로 단다 (Pages 도메인은 저장소 하나에만 연결된다)
